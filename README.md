# Fallout PCB Badge

A unique Fallout-inspired PCB name badge that doesn't look boring like most convention badges.

This badge combines hardware and software into a functional wearable featuring animated LEDs, NFC support, and multiple lighting modes.

## Features

- Multiple LED animation modes
- Push button to cycle through effects
- Integrated NFC functionality
- Custom-designed NFC antenna coil
- Powered by a microcontroller
- Stylish PCB badge design inspired by the Fallout universe

## NFC

The badge includes a custom NFC coil connected to an NFC controller.

Program it with your own data, such as:
- Your website
- GitHub profile
- LinkedIn
- Portfolio
- Contact information
- Any URL of your choice

Anyone can simply tap the badge with their NFC-enabled phone to instantly access your link.
